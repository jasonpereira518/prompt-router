# Omni interface

Operate mode. Familiar sidebar and transcript, as proposed in the approved source specification. Restrained cool slate surfaces, crisp white reading area, forest green for primary actions. System sans for controls and reading; monospace only for code. System theme reflects the user's current lighting preference with explicit override.

Desktop uses a 264px history sidebar and a centered 760px conversation column. Mobile uses an explicit history toggle and full-width transcript. Settings is a dedicated task surface with tabs and rows rather than dashboard cards. All icon controls have labels and visible focus. Error, pending, interrupted, empty and unavailable states remain explicit.
