# Omni

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User-approved Next.js, React, TypeScript, SQLite. One self-hosted server and OmniRoute; Mac client follows.

## Users

Jason, using a private hosted chat interface across devices for daily work.

## Product Purpose

One chat workspace with automatic quality, speed, and cost routing through connected models, shared history, attachments, and provider setup.

## Operating Context

Public HTTPS URL restricted to one owner. Gateway stays private. Subscription and API connections coexist; paid routes require global enablement.

## Capabilities and Constraints

Streaming and Stop; explicit retry records; safe Markdown; images, text PDFs, DOCX and plain text; no silent context omission; server persistence. All gateway providers appear, with guided external setup for unsupported browser connections. No agents, OCR or knowledge library in v1.

## Brand Commitments

Omni is the working name. Honest unknown usage and reported model metadata. System theme with manual override.

## Product Principles

Preserve user work. Gateway owns routing. Restrict paid and vision eligibility throughout fallback. Keep credentials server-side. Show recoverable errors.

## Accessibility & Inclusion

Keyboard access, visible focus, descriptive labels, responsive layout, IME-safe composer.
